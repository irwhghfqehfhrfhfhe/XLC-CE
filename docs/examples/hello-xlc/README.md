# 示例插件：hello-xlc（设置页 + 侧栏页面）

一个**双页面的完整示例**：设置页（`panel.html`）+ 侧栏页面（`page.html`），两个 HTML 共用同一份插件数据。

## 设置页（panel.html）

演示「插件自己的设置」—— 设置项由插件自己定义，值存在插件自己的目录里，
跟启动器设置页互不影响：

1. `storage.get` —— 读出上次存的那份偏好（没有就返回 `null`，用默认值）
2. 把值填进表单（称呼 / 面板主题 / 保存后提示 / 顶部显示启动器版本）
3. `storage.set` —— 点保存，写回插件自己的 `.xlc-data.json`
4. `storage.remove` —— 「恢复默认」把那份删掉

面板顶部那行版本号来自 `launcher.info`，弹提示来自 `notify` —— 清单里只申请这三项
（`notify` / `storage` / `launcher`），**不需要 `control`**：插件自己的设置，不用碰启动器设置。

## 侧栏页面（page.html）

包根目录放一个 `page.html`，启动器**侧栏就会多出一项**（名字来自清单的 `pageTitle`，
图标用 `Images/Logo.png`）。点开在主窗口里直接切换过去 —— 不开新窗口，和启动器自带的页面一样：

- 显示「你好，×××」—— 称呼就是**设置页存的那份**（两个 HTML 共用同一份 storage）
- 「发一条通知」演示 `notify`；「读启动器版本」演示 `launcher.info`
- 不想要页面？把 `page.html`（连同 `page.js` / `page.css`）从包里去掉即可

## 怎么装进启动器

1. 把**本目录里的文件**（不是目录本身）打成 zip：
   - Windows：进到本目录，全选全部文件（含 `Images` 文件夹）→ 右键 → 「压缩为 ZIP 文件」，
     然后把压缩包改名为 `hello-xlc.zip`。
     ⚠️ 别直接右键**文件夹**去压缩 —— 那样包里会多一层 `hello-xlc/` 目录，启动器会提示
     「插件包里缺少 plugin.json」。
   - 命令行：`cd docs/examples/hello-xlc && zip -r ../hello-xlc.zip .`
2. 打开启动器 → 侧栏「导入」→ 「导入插件」→ 选择 `hello-xlc.zip`
3. 弹窗里会把申请的权限逐条列出来（三项都是低风险，直接勾着导入即可）。
4. 侧栏「插件」→ 找到「示例插件」→ 点「打开」是**设置页**；点侧栏的「示例页面」是**页面**。
5. 改一下称呼、点「保存设置」，再去侧栏页面看 —— 「你好，×××」已经跟着变了。

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `plugin.json` | 插件清单：id、名称、版本、入口页面、页面名（`pageTitle`）、申请的权限 |
| `panel.html` / `panel.js` / `panel.css` | 设置页：结构 / 与启动器通信（`window.xlcPlugin.call`）/ 样式 |
| `page.html` / `page.js` / `page.css` | 侧栏页面：结构 / 逻辑 / 样式 |
| `Images/Logo.png` | 侧栏入口图标（文件名必须是 `Logo.png`） |

## 改它之前值得知道的几条

- **设置项由你定，但要给默认值**：模板把默认值集中写在 `DEFAULTS` 里，读出来缺哪个补哪个 ——
  以后加新选项，老用户存的那份也不会坏。
- **存储有上限**：一个插件总共 64 KB，存偏好、缓存几个值够了，别塞图片。
- **主题跟随**：`info().theme` 是启动器当前主题；自己做了「面板主题」选项就按用户的来。
- **页面与面板同一套安全规则**：同一把桥、同一套权限、同一份 CSP —— 页面也一样上不了网、
  碰不到启动器界面。
- **想改启动器设置是另一回事**：那需要 `control` 权限（`config.schema` / `get` / `set` / `reset`），
  而且「不能把任何东西藏起来」是启动器那边的硬红线，详见开发文档 §4.3。
